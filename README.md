## Run locally

```bash
# clone the repo
git clone https://github.com/pavanklyn/pavan-kalyan-portfolio.git
cd pavan-kalyan-portfolio

# install dependencies
npm install

# start the dev server
npm run dev

# build for production
npm run build
```

The production build is created in the `dist` folder.

## Deployment

The site is deployed on Netlify. To deploy a new version, run `npm run build` and upload the `dist` folder.
